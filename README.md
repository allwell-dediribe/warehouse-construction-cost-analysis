# 🏗️ Warehouse Construction Project Cost Analysis Dashboard

## 📌 Project Overview

This project analyzes the financial performance of a warehouse construction project to identify cost drivers, evaluate budget performance, and provide insights that support better project management decisions.

The company had a total project budget of **₦100 million**, but had already spent **₦70 million** while construction was only at the block work stage. The objective of this analysis was to understand where the budget was being consumed, identify potential cost risks, and determine whether the remaining budget would be sufficient to complete the project.

The analysis was performed using **Microsoft Excel**, utilizing PivotTables, PivotCharts, slicers, and dashboard visualization techniques.

---

# 🎯 Business Objectives

The analysis aimed to answer key business questions:

1. Which construction activity consumed the largest portion of the project budget?
2. Which project phases exceeded their planned budgets?
3. Which months recorded the highest expenditure?
4. Which suppliers contributed the highest costs?
5. What materials accounted for the highest spending?
6. Were labour costs a major contributor to budget pressure?
7. What factors were responsible for the project budget overrun?
8. Would the remaining budget be enough to complete the project?
9. What recommendations could improve project cost control?

# 🔍 Key Insights

## 1. Block Work Was the Largest Cost Driver

Block work consumed a significant portion of the project budget and contributed heavily to early budget depletion.

---

## 2. Material Costs Were the Largest Expense Category

Materials represented the highest share of project spending, with blocks and cement being the major contributors.

---

## 3. Budget Consumption Was Ahead of Project Progress

The project had already spent **70% of its total budget** while still being in the early construction stages.

---

## 4. Remaining Budget Was Insufficient

The available **₦30 million** remaining budget was not enough to complete all remaining construction activities, creating an estimated **₦20 million funding gap**.

---

## 5. Supplier Spending Required Monitoring

Supplier analysis highlighted the need for stronger procurement evaluation and cost negotiation.

---

# 💡 Recommendations

Based on the findings:

- Implement regular budget reviews at each construction milestone.
- Improve supplier negotiations to reduce material costs.
- Monitor material usage to minimize waste.
- Perform cost-to-completion forecasts throughout the project.
- Introduce stronger project cost controls before approving additional spending.
- Secure additional funding or reassess project scope.

---

# 📌 Business Impact

This analysis provides management with visibility into:

- Where project funds are being spent

- Whether the remaining budget is realistic
- Where cost-control efforts should be focused

The dashboard transforms raw construction cost data into actionable insights that support better project planning and financial decision-making.
